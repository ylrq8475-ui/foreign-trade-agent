Customer Agent 更新说明
更新时间：2026-05-21

本次更新内容：

1. 新增首次配置页
- 第三方安装后，第一次启动可直接进入 /setup
- 无需手动找到 .env 再编辑
- 可在页面里填写 Google Maps API Key、管理员账号密码、公司信息、SMTP 参数

2. 新增首次配置页内的 SMTP 测试
- 保存配置后可以直接测试 SMTP 是否可用
- 减少“配好了但不知道能不能发”的试错成本

3. 新增“审核并正式发送”按钮
- 在客户详情页中，点击一次即可完成：
  a. 人工审核通过
  b. 正式发送邮件
- 不需要再分别点“人工审核通过”和“审核后正式发送”

4. 审核后自动发送链路已验证
- 人工审核通过后，可按配置自动触发发送
- 发送成功后会自动回写：
  - 客户状态
  - 发送记录
  - 最近发送状态

5. 打包脚本已更新
- 交付目录现在会自动附带：
  - Setup-Guide-CN.txt
  - Release-Notes-CN.txt
- 更方便直接发给第三方使用和查看更新点

建议交付时一并发送：
1. CustomerAgentSetup.exe
2. Setup-Guide-CN.txt
3. Release-Notes-CN.txt
